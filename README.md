# A Novel Computational Framework for Visual Snow Syndrome

This repository contains the source code for the application described and evaluated in the following scientific paper:

> **P. Damiano and O. Gervasi**, *"A Novel Computational Framework for Visual Snow Syndrome,"* in **IEEE Access**, doi: [10.1109/ACCESS.2025.3536923](https://doi.org/10.1109/ACCESS.2025.3536923).

---

## Repository Notice

* **Published Version:** This repository (`DamianoP/visualSnow2024`) acts as the frozen release corresponding to the publication in *IEEE Access*.
* **Active Development:** For the latest updates, bug fixes, and continuous development of the project, please refer to the main repository: **[github.com/DamianoP/visualSnow](https://github.com/DamianoP/visualSnow)**.

---

## Overview

This project introduces an innovative computational framework designed to simulate, study, and alleviate the symptoms of **Visual Snow Syndrome (VSS)**. Utilizing real-time rendering, virtual environments, and human-computer interaction paradigms, the application provides customizable visual filters and immersive experiences to aid research and therapeutic approaches.

### Key Features & Keywords
* **Core Technologies:** Unity, Virtual Reality (VR), Augmented Reality (AR)
* **Domains:** Human-Computer Interaction (HCI), Real-time Systems, Visualization
* **Target Platforms:** Mobile applications, Web browsers, Desktop environments
* **Scientific Focus:** Visual Snow Syndrome, Noise simulation, Real-time camera processing
